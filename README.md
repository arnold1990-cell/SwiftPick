# SwiftPick

Find it. Pick it. Fast.

SwiftPick is a dropshipping store. This repository holds brand assets, product data, documents and marketing material.

## Structure

| Folder | What goes in it |
| --- | --- |
| `assets/logo/` | Logo files (SVG/PNG), brand colors |
| `products/` | Product lists, supplier info, pricing |
| `docs/` | Policies, supplier agreements, business notes |
| `marketing/` | Ad copy, social posts, email templates |

## Brand

- Navy: `#12202B`
- Orange: `#C2410C`
- Font: Outfit
